# Student Information System

A modular Python application designed for managing student records, grade calculations, validation, configuration management, logging, and automated testing.

## Setup Instructions
1. Create a virtual environment: `python -m venv .venv`
2. Activate virtual environment: `.venv\Scripts\activate` (Windows) or `source .venv/bin/activate` (Mac/Linux)
3. Install dependencies: `pip install -r requirements.txt`
4. Run the application: `python -m src.student_app.main`
5. Run tests: `pytest`
